# Manohar Vidyalaya & Jr. College — Website

A responsive static school website built with plain HTML, CSS and JavaScript.

## Included
- Marathi + English branding
- Responsive mobile navigation
- School entrance and activity photos supplied by the school
- About, Academics, Principal, Activities, Gallery, Notices and Contact sections
- No backend or paid service required

## Run locally
Open `index.html` in a browser.

## Free deployment
The site can be deployed for free with GitHub Pages, Netlify, Vercel or Cloudflare Pages.
